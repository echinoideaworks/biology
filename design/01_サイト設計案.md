## 0. 設計の前提（researchを読んで決めたこと）

### 0-1. 全ページ共通の「3つの表示ルール」
research 06 の要確認・議論中の論点を、画面上で常に区別できるようにする。

| バッジ | 意味 | 例 |
|---|---|---|
| **基本** | 高校「生物」の範囲（学習指導要領解説で扱う内容） | 3ドメイン、界・門、旧口/新口 |
| **発展** | 大学レベル・最新研究。全体スイッチ「発展も表示」で開閉 | スーパーグループ、2ドメイン説、Spiralia |
| **議論中** | 研究上決着していない。点線・多分岐・仮説切替で描く | 海綿先行か有櫛先行か、珍無腸動物 |

- ヘッダーに **「基本／発展」の切替スイッチ** を常設。発展をOFFにすると高校範囲だけの画面になる。
- 系統樹の **未解決の枝は多分岐（くし状）**、議論中の枝は **点線**。出典のない分岐は描かない（R06 §4）。
- すべての枝・主張に `sourceId`（05のID：P23 など）をデータとして持たせ、図の「出典」ボタンから参照できるようにする。

### 0-2. 用語の初期設定（教科書で照合するまで）
- 「旧口動物（前口動物）」「新口動物（後口動物）」と併記（R02 §3.1）。
- 「古細菌（アーキア）」と併記。
- ミミズの「心臓」の対数、脊索動物の共通特徴の数は、**断定しない表記**を初期値にする（R06 §5 #5, #6）。教科書が決まれば差し替える。

### 0-3. デザインの軸（参考画像から）
参考画像（ライトテーブル上の植物図版、重なった透明シート、木の標本ラベル）から、次の3つをUIの基本要素にする。

1. **ライトテーブル**：図版の背後がやわらかく光る、オフホワイトの台。生物図版はこの上に「置かれる」。
2. **透明シートの重ね合わせ**：解剖図の層（体腔・消化管・神経…）や、分類体系の変遷を「シートを重ねる・めくる」操作で見せる。参考画像の操作感をそのまま情報の構造に使う。
3. **標本ラベル**：詳細パネルは、和名・学名・門・出典を記した標本ラベルの体裁にする。

配色：背景 #F5F1E8 前後のオフホワイト〜生成り、文字は濃いグレー（#2E2B27 前後）、系統樹は落ち着いた緑。9つの門には、識別しやすい土・植物系の色を割り当てる（彩度は控えめ）。ネオン、HUD、粒子演出、グラデーション過多は使わない。

## 1. サイトマップ

1つのHTML（index.html）で、URLのハッシュによりページを切り替える。ダブルクリックで開いてもローカルで動く構成にする（§6）。

```
index.html
├─ #/                 P01 進化と分類の全体像（トップ）
├─ #/history          P02 分類体系の歴史
│    └─ #/history/:system   （二界説／三界説／五界説／三ドメイン説／スーパーグループ）
├─ #/atlas            P03 動物の分類図鑑（9つの門の一覧）
│    └─ #/atlas/:phylum     各門の詳細（例：#/atlas/echinodermata）
│         └─ ?sp=:species   代表生物の切替（例：?sp=hitode）
├─ #/tree             P04 系統樹を探索する
│    └─ #/tree?focus=:node   ノードを選んだ状態で開く
├─ #/compare          P05 体のつくりを比べる
│    └─ #/compare/:a/:b      （例：#/compare/nematoda/annelida）
├─ #/eukaryotes       P06 真核生物のスーパーグループ図鑑
│    └─ #/eukaryotes/:group
└─ #/about            P07 出典・凡例・この教材について（新規追加を提案）

全ページ共通
├─ ヘッダー：サイト名／6ページへのナビ／検索／基本⇔発展スイッチ
├─ 検索オーバーレイ（生物から探す／特徴から探す）
└─ 標本ラベル・ドロワー（右から出る詳細パネル。どのページからでも同じ部品）
```

**P07を足す理由**：画像の出典とライセンス、research の要確認事項、採用した分類体系を、教材の中で一か所にまとめて示す必要があるため（R05 §6、R06 §6）。

### ページ間の連動（「探索」の導線）
- 生物をクリック → 標本ラベル・ドロワー →「図鑑で詳しく（P03）」「系統樹で位置を見る（P04）」「ほかの門と比べる（P05）」
- 系統樹のノード（共通祖先）をクリック → その系統群の説明 →「この群の生物」一覧
- 図鑑の「系統樹上の位置」ミニ樹をクリック → P04がそのノードに寄った状態で開く
- 歴史ページで生物トークンをクリック → その生物の現在の分類位置へ

### P02　分類体系の歴史

**中心となる考え方**：**同じ16種類の生物**を画面に置き続け、分類体系が変わると**生物はそのままで、囲む「境界線」が組み替わる**ように見せる。分類とは「生物そのもの」ではなく「人がどこに線を引くか」だと示せる。一本道の発展にも見えにくい。

```
┌────────────────────────────────────────────────────────────┐
│ 左：説明パネル（スクロールで切替）    │ 右：ステージ（固定表示）           │
│ ─────────────────────── │                              │
│ 二界説  18世紀〜 リンネ ほか        │   ┌ 植物界 ──────┐ ┌ 動物界 ──┐ │
│ 目的：博物学的な整理              │   │ サクラ  コンブ   │ │ ウニ    │ │
│ 基準：動く／光合成する（外見）       │   │ シイタケ ケイ藻  │ │ ゾウリムシ│ │
│ 説明できなかったこと：             │   │ ミドリムシ?  …  │ │ アメーバ  │ │
│  ミドリムシは動き、光合成もする ← 点滅 │   └────────────┘ └───────┘ │
│ 現在の位置づけ：歴史的な体系          │   ※ ミドリムシ が境界線上で揺れる │
├────────────────────────────────────────────────────────────┤
│ 下：タイムライン  18世紀 ─ 1866 ─ 1969 ─ 1977 ─ 1990 ─ 2005 ─ 2012 ─ 2019/2020│
│ 年号は R01 §3・R05 §7 で確認したものだけ。未確定の年（Copeland、Chatton）は出さない │
└────────────────────────────────────────────────────────────┘
```

- **16の生物トークン（固定）**：
  - 動物：ウニ、ヒト
  - 植物・藻類：サクラ、コンブ（褐藻）、アサクサノリ（紅藻）、クラミドモナス
  - 菌類・粘菌：シイタケ、アオカビ、モジホコリ（粘菌）
  - 原生生物：ミドリムシ、ゾウリムシ、アメーバ、ケイ藻、襟鞭毛虫
  - 原核生物：大腸菌、メタン生成菌
- **スクロールの5段階と変形**：
  1. **二界説**：植物／動物の2つの境界。ミドリムシ、粘菌、細菌が境界線上で揺れる（＝説明できなかったこと）。
  2. **三界説（Haeckel、1866※二次資料）**：「原生生物」の境界が新しく現れ、単細胞のものが移動する。細菌と核をもつ単細胞生物が同じ枠に入っている点を強調する。
  3. **五界説（Whittaker 1969）**：モネラ・原生生物・菌・植物・動物。シイタケとアオカビが植物界から「菌界」へ移る。各界に**栄養様式のアイコン（生産者／分解者／消費者）**が付く。この体系は系統ではなく栄養と細胞のつくりで分けた、と明示する（R01 §1）。
  4. **三ドメイン説（Woese 1977→1990）**：境界が一度ほどけ、**rRNAの配列比較による枝**に描き直される。大腸菌とメタン生成菌が別のドメインに分かれる。「1977：原界（urkingdom）」「1990：ドメイン」を書き分ける（R06 §8）。
  5. **スーパーグループ（Adl 2005〜2019、Burki 2020）**：**真核生物ドメインの円の中へズームイン**する遷移。階層が違うこと（三ドメイン＝全生物の最上位、スーパーグループ＝真核生物の内部）を、ズームという動きそのもので示す。
- **「並べて比べる」モード**：5つの体系を横並びの縮小図にし、それぞれの「目的・基準・単位」を表で比べる。時間順の一本道ではなく、**目的の異なる提案の並び**として見せる（R01 §3）。
- **補足（発展）**：
  - Cavalier-Smith の6〜9界説は、「八界説」の呼称を避け「7〜9界を比較」と表記する（R06 §5-2）。
  - 2ドメイン説・アスガルド古細菌は「議論中」バッジを付けて表示する。
- **各体系のパネルの共通項目**：時代／提唱者／基準／当時の背景／説明できなかった問題／何が変わったか／現在の位置づけ／出典。

### P03　動物の分類図鑑（サイトの中心）

#### 一覧画面（#/atlas）

```
┌────────────────────────────────────────────────────────────┐
│ 動物の分類図鑑         並べ方：[系統樹の順] [体腔] [対称性]        │
├────────────────────────────────────────────────────────────┤
│ ┌標本引き出し─────┐ ┌──────────┐ ┌──────────┐           │
│ │ 大きな全身図     │ │          │ │          │  …全9枚     │
│ │ （ヒトデ）       │ │          │ │          │           │
│ │──────────│ │          │ │          │           │
│ │ 棘皮動物門       │ │          │ │          │           │
│ │ 新口・真体腔・五放射│ │          │ │          │           │
│ └──────────┘ └──────────┘ └──────────┘           │
│ 下部：9枚のカードを結ぶ小さな系統樹（ホバーで該当カードが光る）       │
└────────────────────────────────────────────────────────────┘
```

- カードは **3列×3段**。全身図はカード幅いっぱい（PCで約360px四方）に大きく載せる。
- 並べ方を切り替えると、カードが滑らかに並び替わる。たとえば「体腔」では無体腔／偽体腔／真体腔の3列に並ぶ。その際、偽体腔の列に「系統群ではない」と注記する（R06 §2）。

#### 各門の詳細画面（#/atlas/:phylum）

```
┌────────────────────────────────────────────────────────────┐
│ ← 環形動物  │  棘皮動物門 Echinodermata  基本  │  脊索動物 →       │
├──────────────────────────┬─────────────────────────┤
│                          │ 標本ラベル                   │
│  ライトテーブル上の大きな全身図   │ 和名  マヒトデ                │
│  （画面の約55%）            │ 学名  Asterias amurensis     │
│                          │ 門    棘皮動物門 ヒトデ綱          │
│  ［全身］［解剖］［断面］の切替   │ 生息  浅い海の岩礁・砂泥         │
│  → 解剖では透明シートが重なる   │ 一言  水の圧力で管足を動かす       │
│                          │──────────────────│
│  下：代表生物の切替            │ ミニ系統樹（この門の位置が光る）     │
│  [ヒトデ][ウニ][ナマコ][クモヒトデ]│                         │
├──────────────────────────┴─────────────────────────┤
│ 1 体のつくり │ 2 特徴的な器官 │ 3 発生 │ 4 生活 │ 5 ほかの門との違い │ 6 重要用語 │ 7 発展 │
│ （横に並ぶ節。スクロールで順に読める。各節の右端に出典番号）          │
└────────────────────────────────────────────────────────────┘
```

- **解剖図の操作**：
  - 部位をクリックすると引き出し線が伸び、名前・働き・よくある誤解の吹き出しが出る。
  - 層の切替（シートのON/OFF）：外形／体腔／消化管／神経／循環／その門に固有の器官。
  - ヒトデの水管系では「水の流れを再生」ボタンで、多孔板→石管→環状水管→放射水管→瓶嚢→管足の順に水色の流れがたどる。
- **節の構成**：
  1. 体のつくり
  2. 特徴的な器官（解剖図と連動）
  3. 発生（胚葉、原口の運命、体腔のでき方、幼生）
  4. 生活様式・生態
  5. ほかの門との違い（最も紛らわしい門と並べ、P05への導線を置く）
  6. 重要用語（用語集にリンク）
  7. 発展（例：毛顎動物の位置の変遷、Spiralia の範囲）
- **門ごとの「誤解しやすい点」**：research の「避ける表現」を、正しい説明として本文に組み込む。
  - 例：「ホヤの成体には脊索がない。幼生にはある」
  - 例：「外套膜は貝殻ではない」

### P04　系統樹を探索する

```
┌────────────────────────────────────────────────────────────┐
│ 左パネル（折りたたみ可）          │ 系統樹キャンバス（拡大・移動）          │
│ ─────────────            │                                │
│ 表示範囲  ○ 全生物 ● 動物        │   ┌─ 海綿動物      [図版]           │
│ 強調      □ 旧口/新口           │  ⋔┼─ 有櫛動物      [図版]  議論中     │
│           □ 脱皮動物/冠輪動物    │   ├─ 刺胞動物 …                    │
│           □ 体腔の型（色分け）   │   └─┬─ 左右相称動物                  │
│           □ 体節をもつ門         │      ├┄ 珍無腸動物 （点線）          │
│           □ 対称性              │      ├─┬ 旧口 ─┬ 脱皮 ⋔ 線形・節足   │
│ 最初の分岐 ○ 海綿が先            │      │      └ 冠輪 ⋔ 扁形・環形・軟体 │
│ （仮説）   ○ 有櫛が先            │      └─ 新口 ─┬ 棘皮（＋半索）       │
│           ● 未解決として表示     │                └ 脊索 ─┬ 頭索        │
│ ─────────────            │                       └┬ 尾索 / 脊椎 │
│ 読み方ガイド ▸                  │   右下：ミニマップ   ＋ − ⟲ 全体     │
└────────────────────────────────────────────────────────────┘
選択時：右から標本ラベル・ドロワー（その群の生物図版・共通の特徴・出典）
```

- **形**：長方形（横向き）の樹。円形と切り替えられる。末端に生物の図版（約96px）を置く。
- **操作**：
  - ホイール／ピンチで拡大縮小、ドラッグで移動、ダブルクリックでそのノードに寄る。
  - **分岐点（共通祖先）のクリック**：その子孫すべてを含む範囲（＝単系統群）が色の帯でハイライトされる。ドロワーには「この共通祖先から分かれたグループ」「共有する特徴（出典のあるものだけ）」を出す。
  - **⟲ 枝を回転**：選んだノードの左右を入れ替えるアニメーション。並び順に意味がないことを体験させる（R03 §1）。
  - **強調チェック**：
    - 「体節をもつ門」：環形と節足が光るが、両者の共通祖先ノードは**体節の印なし**で示す。「近縁ではない」ことが見える（R06 §2）。
    - 「体腔の型」：偽体腔の門は離れた枝に散らばる。多系統であることが見える。
  - **仮説スイッチ**：最初の分岐を「海綿が先／有櫛が先／未解決（くし状）」で切り替える。初期値は未解決（R06 §2）。
- **読み方ガイド（基本）**：根・節・枝・末端の説明、単系統／側系統／多系統の体験（鳥類・ワニ類・爬虫類の例。R03 §3で出典を確認済み）を、小さな練習用の樹で示す。
- **時間軸**：枝の長さは**意味をもたない（クラドグラム）**と常に表示する。時間樹は、年代の出典（TimeTree等）を確認するまで作らない（R06 §4-13）。
- **全生物の範囲**では、3ドメインを根元に置き、真核生物の枝からP06へ移れる。

### P05　体のつくりを比べる

```
┌────────────────────────────────────────────────────────────┐
│ 比べる組み合わせ： [扁形×線形] [線形×環形] [環形×節足] [軟体×節足] [棘皮×脊索] [自由に選ぶ ▾] │
├──────────────────────────┬─────────────────────────┤
│  プラナリア（扁形動物）         │  回虫（線形動物）               │
│  ┌全身図┐                  │  ┌全身図┐                     │
│  ┌横断面（同じ向き・同じ縮尺）┐   │  ┌横断面┐                     │
│   体壁｜（体腔なし）｜腸         │   体壁｜偽体腔｜腸               │
├──────────────────────────┴─────────────────────────┤
│ 重ねる層：[体の形][体節][体腔][消化管][神経][骨格・支持][特徴的な器官] │
├────────────────────────────────────────────────────────────┤
│ 比較表   項目     │ 扁形動物        │ 線形動物                     │
│         体腔     │ なし（無体腔）    │ 偽体腔        ← 違う行は色付き │
│         消化管   │ 口のみ（肛門なし） │ 口→肛門（完全）              │
│         系統     │ 冠輪動物         │ 脱皮動物                     │
├────────────────────────────────────────────────────────────┤
│ 2つの共通祖先：ミニ系統樹でノードが光る（「前口動物の共通祖先で分かれた」）   │
└────────────────────────────────────────────────────────────┘
```

- **層の同期**：左右の断面図は同じ縮尺・同じ向き（背側を上）で描く。層を選ぶと**両方の同じ層だけが色付き**になる。たとえば「体腔」を選ぶと、左は何も光らず、右は偽体腔が光る。違いがひと目でわかる。
- **共通部分と違う部分**：比較表で値が異なる行に色を付ける。表の行をホバーすると、対応する図の部位が光る。
- **組み合わせごとの見どころ**：

| 組み合わせ | 見せたい点 | 動き |
|---|---|---|
| 扁形 × 線形 | 無体腔と偽体腔、口だけの消化管と口から肛門への消化管 | 食べ物の粒が消化管を通る（扁形では同じ口へ戻る） |
| 線形 × 環形 | 偽体腔と真体腔、体節の有無、縦走筋のみと環状筋＋縦走筋 | 体の動き方の比較（鞭のようにくねる／蠕動運動） |
| 環形 × 節足 | どちらも体節をもつが、冠輪動物と脱皮動物で近縁ではない | 体節を光らせたあと、系統樹で離れた枝を示す |
| 軟体 × 節足 | 外套膜と外骨格。殻の有無は系統と無関係 | 頭足類の殻の退化（オウムガイ→イカ→タコ）、発展 |
| 棘皮 × 脊索 | どちらも新口動物。幼生の左右相称と成体の五放射相称 | ウニの幼生から成体への変態、ホヤ幼生と脊椎動物胚 |

- **特別ビュー（体腔の3つの型）**：無体腔・偽体腔・真体腔の断面を並べ、その形成（裂体腔・腸体腔）を、胚の断面が変化するアニメーションで見せる。

## 4. イラストの制作方法（要判断）

全身図約68点の作り方で、品質・統一感・権利の扱いが大きく変わります。

| 案 | 内容 | 長所 | 短所 |
|---|---|---|---|
| **A. すべて自作のSVG**（推奨） | 全身図も解剖図も、research と資料写真で形を確かめながら、同じ線と色のルールでSVGを描く | タッチが完全にそろう。権利の問題がない。解剖図と同じ部品を使い回せ、部位をクリックできる | 写真のような細密さは出ない（「精密な線画＋淡い彩色」の図鑑タッチが上限）。点数が多く時間がかかる |
| B. パブリックドメインの古典図版を中心に使う | ヘッケル『生物の驚異的な形』（1904）などの図版を、Wikimedia Commons／BHL から1点ずつ権利を確認して取り込む | 微生物（放散虫・ケイ藻・渦鞭毛藻）の図版が非常に美しい | 図版によってタッチがばらつく。学名や形態が古い場合がある。動物の網羅には足りない |
| C. A＋B | 全身図・解剖図は自作SVGで統一し、P06の顕微鏡の視野にだけ古典図版を「原典図版」として並べて載せる（出典表記付き） | 統一感と、本物の図版の魅力を両立できる | Bの権利確認の手間がかかる |

- どの案でも、画像は `assets/` に置き、`organisms` データの `image` を差し替えるだけで交換できる構造にします。あとからご自身で描いた絵や撮影した写真に置き換えることもできます。
- 写真を使う場合は CC BY／パブリックドメインに限り、作者・ライセンス・URLを `sources` データに記録して P07 に自動で一覧表示します。OpenStax Biology 2e（CC BY-NC-SA）と教科書の図版は使いません（R06 §6-A3）。
